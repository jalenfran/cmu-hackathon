Pipeline

Real-Time Data Pipeline

1. Data Ingestion

Transactions from Capital One Nessie API or our mock generator (14 fraud scenarios, 8% anomaly rate). Published to Redpanda (Kafka-compatible, zero JVM).

2. Feature Extraction

8 features per transaction: amount, log-amount, hour, day-of-week, international flag, velocity (Redis sliding window), distance from last location, per-account z-score.

3. Anomaly Detection

Isolation Forest (100 trees) + FAISS novelty scoring + rule-based boosting. If score > threshold, alert is created and queued for investigation.

# Feature extraction pipeline features = { "amount": txn.amount, "log_amount": log(txn.amount + 1), "hour": txn.timestamp.hour, "day_of_week": txn.timestamp.weekday(), "is_international": int(is_intl), "velocity": redis.get_velocity(acct), "distance": haversine(last, curr), "z_score": (amt - mean) / std, } # Score → flag → investigate score = isolation_forest.score(features) score += faiss.novelty_boost(acct, txn) if score > threshold: alert = create_alert(txn, score) queue.put(alert)
AI Agents

Autonomous Investigation with ReAct Agents

Each flagged transaction is investigated by an AI agent running Llama 3 locally via Ollama. The agent uses a ReAct reasoning loop — thinking, acting, and observing — up to 6 steps.

Human-in-the-Loop

When the AI is Uncertain, Humans Decide

When the agent's confidence is low, it flags the alert for human review instead of making a risky autonomous decision.

1. Agent verdict: FLAG_FOR_REVIEW (confidence: 52%)
2. Slack notification → #human-reviews
3. Analyst sees full evidence trail + agent reasoning
4. Human decides: Block Account or Clear Transaction
5. Decision stored in FAISS → future agents learn from it
6. Follow-up Slack notification with resolution

Adaptive Learning

Adaptive Shield — The System Gets Smarter

Every verdict — from the AI agent or a human analyst — is embedded as a vector and stored in FAISS. Future investigations query these past cases to inform their decisions.

How It Works

  • Transaction + verdict text → SentenceTransformer → 384d vector
  • Stored in FAISS investigation index with metadata
  • Agent tool find_similar_investigations retrieves top-k matches
  • Human verdicts tagged verdict_source: "human" for higher weight
  • No model retraining required — adapts through retrieval
